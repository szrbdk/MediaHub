# MediaHub 1.0.0

MediaHub brings playback controls, now-playing updates, and automatic song filtering to your Mac's menu bar and Touch Bar.

## Features

- Touch Bar playback controls, track information, and an expanded seek bar.
- 15-second skip controls for Podcasts.
- Artwork notifications near the camera when tracks change or playback pauses or resumes.
- Music favorites you can add or remove from the Touch Bar.
- Song and artist blacklists with automatic skipping.
- Independent toggles for Touch Bar controls, notifications, and automatic skipping.
- English and Turkish interfaces with saved preferences.

## Install

1. Download **MediaHub-1.0.0.dmg** from the assets below.
2. Open the disk image and drag **MediaHub** into **Applications**.
3. Eject the disk image and open MediaHub from Applications.
4. Use the MediaHub menu bar icon to configure the app.

**Requirements:** macOS 27.0 or later. The universal app contains Apple Silicon and Intel binaries. Touch Bar controls require a MacBook Pro with a Touch Bar. No Xcode installation is needed to use the app.

## Before opening

This build is ad-hoc signed and is not notarized by Apple. macOS may block the first launch. If you trust this download, try opening the app, then go to **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/en-gb/102445).

Music favorites may also require macOS automation permission. MediaHub uses private macOS APIs, so controls and available information may vary with the player and system version.

The accompanying `.sha256` file provides the DMG's SHA-256 checksum.
